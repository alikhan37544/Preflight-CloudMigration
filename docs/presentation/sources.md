## 4. Source discipline used in the deck

- **VERIFIED** means a public URL resolved and the quoted/paraphrased claim is visible on the page. It does not mean the whole page was independently audited.
- **GATED** means the public page exists but the body, threshold, or corpus is not public. No attempt is made to infer the gated content.
- **VENDOR CLAIM** means the statement is the vendor’s estimate or positioning, labelled as such. The 6–8 week number is the clearest example: it covers APD product conversion, not a full migration.
- **SECONDARY** means an experience report or blog, not a standard. The JDBC/servlet/commit examples are treated as secondary evidence.
- **HEURISTIC** means a PreFlight pattern. It is not a Cloud Standard and is labelled `heuristic` in the UI.
- **NOT MEASURED** means a design premise from practice; “incomplete handover” is the example on slide 2.

## 5. Deck asset provenance

The screenshots in `docs/presentation/assets/` were captured from the running application at `http://127.0.0.1:8000/?run=R-DEMO-001` on 2026-11-09 using `scripts/capture_demo.py`. The deck uses content crops (`workbench-focus`, `manifest-focus`, `findings-focus`, `packet-focus`, `reconstruction-after-decision-focus`) so the relevant text is legible on a projector; the full-viewport captures remain in the package. Focus crops keep a 50 px left gutter so numbered markers sit beside, not on, the text; the capture script validates each crop’s section boundaries and required labels against the live DOM and records the proof in `capture-manifest.json`.

The reconstruction and packet “after reviewer actions” captures were taken from an isolated copy of the same run and build: temporary `PREFLIGHT_DATA_DIR`, second loopback Uvicorn, Accept M-01 then Reject M-12. That produces **11 audit events / 4 assumptions / A-DEC-04**; the live demo run remains at 12 pending / 3 assumptions / 9 events. The script deletes the copy and stops the second server.

`findings-guard-query-make.png` is an element crop of the precision-guard card (`Query.make` supported, not JDBC). The deck replay proofs are the `deck-slide-XX-<viewport>.png` files; validation results are in `assets/deck-validation.json`; measured marker positions are in `assets/marker-hints.json`. See `docs/presentation/assets/capture-manifest.json` for file hashes, capture URLs, and post-decision facts.
