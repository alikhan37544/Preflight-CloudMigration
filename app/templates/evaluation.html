Full limitations
  • One synthetic fixture plus a pre-computed naming-shift holdout. This is not a benchmark and not a generalisation claim.
  • The holdout is never imported into the demo, never used for tuning, and is not re-run here.
  • No live tenant, customer code, Cloud API generation, deployment, or official Cloud Assurance run.
  • M5 uses a fixed {{ evaluation.m5_top8.fraction if evaluation.m5_top8 else 'top-8' }} top-8 allowance, not a learned ranking. M6 has no interval at this n. M3 checks excerpt support, not semantic entailment.

Full limitations, caveats, and pre-registration notes expand
  • One synthetic main fixture plus a naming-shift holdout. Not a benchmark and not a generalisation claim.
  • No live tenant, no customer code, no Cloud API generation, and no deployment.
  • Findings are pattern-based and advisory. Official Cloud Assurance was not run.
  • Impact ranges are heuristic planning ranges, not quotes or measured productivity.
  • Demo metrics are in-sample on the development slice; the naming-shift holdout is pre-computed and never imported.
  • M3 audits excerpt support at the source, not semantic entailment. The M6 scoring corpus uses three positives and three hard negatives per rule; the findings table lists observed findings only, not the corpus rows. No F1 interval is shown at this n.
  • No human inter-annotator study was run; the reference target and concordance process are labelled AI-assisted.
  • The reference target is internally authored by the same build team, not independent; this is reported as a limitation.
