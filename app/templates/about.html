About PreFlight

An offline, evidence-first cloud-readiness review product for Guidewire-style legacy estates. Independent research prototype.

What it is

PreFlight assembles feature candidates across PCF, entity metadata, typelists, extracted templates, Gosu, and Cloud API configuration; links every claim to file evidence; surfaces documented blockers and gaps; and produces a reviewable local Cloud API extension draft plus an impact-rated assumption register for one feature slice.

What it is not

  • It does not convert products to APD and does not replace Cloud Retrofit.
  • It does not produce an official Cloud Assurance result, score, or certification.
  • Not a generic Gosu linter; SonarQube and Cloud Assurance own generic linting.
  • Not a live-tenant connector or deployment tool.
  • The Migrator is an autonomous draft generator: it writes a local, non-deployable bundle and leaves every change pending human approval. It does not connect to a tenant or deploy code.
